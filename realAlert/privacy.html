🔒 실거래 알림 개인정보 처리방침

홍부가 기가막혀 · 실거래 알림 · 판 2026-10-13 (시행 2026년 10월 13일)
홍부 실거래 알림은 사용자가 고른 아파트 단지에 새 매매 실거래가 신고되면 텔레그램과 홍부 화면으로 알려 주는 기능입니다. 이 기능을 쓰려면 아래 정보를 서버에 저장해야 하며, 알림 발송 외의 목적으로는 쓰지 않습니다. 광고·판매·제3자 제공을 하지 않습니다.

1. 저장하는 정보

알림 키브라우저에서 무작위로 만든 32자 문자열. 사용자를 구분하는 유일한 값이며, 이름·이메일·전화번호와 연결하지 않습니다.
관심 단지고른 단지의 단지번호·단지명·시도·시군구·등록 일시
알림 설정알림 시각, 마지막 발송 시각, 읽음 표시, 마지막 접속 시각, 동의 일시·판
텔레그램대화방 번호만 저장합니다. 텔레그램 사용자명·이름·전화번호는 저장하지 않습니다.
발송 기록발송 시각·건수·결과. 대화방 번호는 끝 4자리만 남깁니다.
접속 기록서버와 전송 경로(Cloudflare)가 남기는 IP 주소·접속 시각 등 일반적인 접속 기록

2. 이용 목적

  • 고른 단지의 새 매매 실거래를 정해진 시각에 텔레그램으로 보내기
  • 홍부 화면에 오늘의 알림(🔔)과 알림 단지를 보여 주기, 같은 키를 쓰는 기기끼리 읽음 상태 맞추기

3. 보관 기간과 파기

  • 사용자가 삭제를 요청하면 즉시 서버에서 지웁니다(아래 5번).
  • 발송 기록·로그: 90일 뒤 자동 삭제
  • 텔레그램 봇을 차단해 끊긴 연결: 30일 뒤 자동 삭제
  • 텔레그램 연결이 없고 1년 동안 홍부 접속도 없는 키: 관심 단지·설정까지 통째로 자동 삭제
  • 파기는 서버 데이터베이스에서 해당 행을 지우고, 로그 파일에서 해당 줄을 잘라 내는 방식입니다.

4. 국외 이전·처리를 맡기는 곳

Oracle Cloud서버·데이터베이스 보관 — 일본 도쿄 리전. 위 1번 정보 전부가 이 서버에 저장됩니다(서비스 이용 시 네트워크로 전송).
Cloudflare (미국)서버로 가는 접속의 전송·보안 중계. 요청 내용이 거쳐 갑니다.
Telegram알림 메시지 전달. 메시지 내용은 텔레그램의 정책에 따라 처리됩니다.
GitHub Pages (미국)홍부·알림 페이지 제공(접속 기록)
Google Drive구글드라이브에 로그인한 경우 사용자 본인의 드라이브에 알림 키와 관심 단지 백업 파일(HongbuMemo/realAlert_targets.json)을 저장합니다. 운영자는 이 파일을 볼 수 없습니다.
이전 시기: 알림을 켜고 이용하는 동안 · 방법: 암호화된 연결(HTTPS)로 전송 · 보관 기간: 위 3번과 같음

5. 사용자의 권리

  • 보기·고치기: 홍부 [도구] → 실거래 알림 → [🔔 알림 단지 관리]에서 저장된 단지와 설정을 보고 바꿀 수 있습니다.
  • 모두 삭제: 관리창의 [내 알림 데이터 모두 삭제] 또는 텔레그램 봇에 /delete
  • 알림만 그만 받기: 텔레그램 봇에 /stop(텔레그램 연결만 삭제)
  • 동의 거부: 동의하지 않아도 홍부 지도는 그대로 쓸 수 있고, 실거래 알림만 쓸 수 없습니다.

6. 안전하게 지키는 방법

  • 모든 전송은 HTTPS로 암호화합니다.
  • 정보는 무작위 알림 키로만 조회·변경됩니다. 키는 추측이 사실상 불가능한 길이(128비트)이며, 키를 남에게 알리지 않는 것이 중요합니다.
  • 화면과 로그에는 텔레그램 대화방 번호를 가려서 보여 줍니다.
  • 서버 접근은 운영자의 인증 키로만 가능합니다.
처리방침이 바뀌면 이 페이지에 판을 올리고, 알림을 켤 때 다시 동의를 받습니다.
